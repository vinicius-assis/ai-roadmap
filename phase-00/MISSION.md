# Mission: AI Engineer foundations (Phase 0 of the roadmap)

## Why
Vinícius is making a deliberate career switch from frontend/full-stack web development
into AI Engineering — building LLM and agent products for a living. He is enrolled in
the UNIPDS pós-graduação "Engenharia de Software em IA Aplicada" and following the
roadmap in `../roadmap.md`. Phase 0 exists so the later phases (LLM APIs, RAG, agents,
production) land on solid ground instead of fighting prerequisites.

## Success looks like
- Reads and writes modern async TypeScript fluently: Promises, `async/await`,
  `try/catch`, and consuming a token stream with `for await...of`
- Can call a REST/LLM API defensively: timeouts, retry with backoff, handling 429 rate limits
- Can explain and compute a dot product and cosine similarity, and say why they matter for embeddings
- Has enough probability intuition to reason about sampling, `temperature`, and `top_p`
- Ends Phase 0 with a small TS script that streams tokens from a model API — the seed of Phase 1

## Constraints
- 5–8 hours/week (roughly an hour a day)
- Stack is JavaScript/TypeScript (matches the course and the roadmap)
- Strong on JS fundamentals and Git already; weak spots are TS types, async, and the math
- Prefers self-contained, resumable lessons

## Out of scope (for now)
- Python, fine-tuning, model training
- Deep linear algebra / calculus beyond what embeddings need
- Framework specifics (LangChain, LangGraph) — those are Phase 4+
- Git/GitHub instruction — already solid
