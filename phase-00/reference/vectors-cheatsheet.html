Colinha de Vetores & Cosseno

A matemática de embeddings, comprimida. Imprima e revise antes das lições de RAG.

Vocabulário

TermoÉ
Vetoruma lista de números, number[]. Cada número é uma coordenada num eixo.
Embeddingo vetor que um modelo produz pra representar o significado de um texto (ex.: 1536 números na OpenAI).
Produto escalar (a · b)componente a componente, multiplica e soma. Resultado: um número.
Norma / magnitude (‖v‖)comprimento do vetor: √(Σ vᵢ²).
Normalizar (unitário)dividir cada componente por ‖v‖ → novo vetor de comprimento 1, mesma direção.
Similaridade de cossenocosseno do ângulo entre dois vetores: (a · b) / (‖a‖ ‖b‖). Faixa [−1, 1].
top-kos k vetores com maior similaridade contra a consulta.

Fórmulas

a · b   = Σ aᵢ·bᵢ                    // (1·2)+(2·0)+(2·1) = 4
‖v‖     = √(Σ vᵢ²)  = √(v · v)       // √(1+4+4) = 3
cos(a,b) = (a · b) / (‖a‖ · ‖b‖)     // 4 / (3 · 2.236) ≈ 0.596
unit(v)  = v / ‖v‖                    // comprimento vira 1

Implementação de referência (TS)

const dot = (a: number[], b: number[]) =>
  a.reduce((s, x, i) => s + x * b[i], 0);

const norm = (v: number[]) => Math.sqrt(dot(v, v));

const cosine = (a: number[], b: number[]) =>
  dot(a, b) / (norm(a) * norm(b));

const unit = (v: number[]) => {
  const n = norm(v);
  return v.map((x) => x / n);
};

Pegadinhas

  • Produto escalar cru mistura alinhamento com comprimento. Use cosseno, a menos que os vetores já sejam unitários.
  • Se os embeddings já vêm normalizados (OpenAI, a maioria): cos(a,b) = a · b. Bancos vetoriais chamam isso de "inner product".
  • sort sem comparador ordena como string. Sempre .sort((a,b) => b.score - a.score).
  • Vetores de tamanhos diferentes não têm produto escalar — os dois embeddings precisam vir do mesmo modelo.
  • Distância euclidiana e cosseno dão a mesma ordem quando os vetores são unitários; fora disso, não.
