Colinha de Amostragem

Como um LLM escolhe o próximo token, comprimido. Imprima e revise antes das lições de API.

Vocabulário

TermoÉ
Logito número bruto que o modelo produz por token (pré-softmax). Pode ser negativo; não soma 1.
Softmaxconverte logits em probabilidades: exp(lᵢ) / Σ exp(lⱼ). Exponenciar amplifica diferenças.
Amostrador (sampler)o que sorteia o próximo token a partir da distribuição de probabilidade.
Greedy decodingsempre pegar o token de maior probabilidade. É o limite de temperature → 0.
temperature (T)divisor dos logits antes do softmax: softmax(lᵢ / T). Controla o quão afiada é a distribuição.
top_p (nucleus)mantém o menor conjunto do topo cuja prob. acumulada ≥ p; descarta a cauda; renormaliza.
top_kmantém os k tokens mais prováveis (número fixo). Menos usado que top_p.

Fórmulas

softmax(l, T)ᵢ = exp(lᵢ / T) / Σⱼ exp(lⱼ / T)

// estabilidade numérica: subtraia max(l/T) de cada termo antes do exp
// (resultado idêntico, evita Infinity)

top_p:  ordene p decrescente; some até passar de p; fique com esse prefixo; renormalize
top_k:  ordene p decrescente; fique com os k primeiros; renormalize

O que a temperature faz

TEfeito na distribuiçãoComportamento
→ 0um token com ~100%greedy; quase determinístico; repetitivo
< 1mais afiada (diferenças ampliadas)focado, previsível — extração, código, classificação
= 1distribuição crua do modelopadrão da maioria das APIs
> 1mais plana (cauda ganha peso)criativo; alto demais → incoerência

Faixas e regras por provedor

  • Anthropic: temperature 0.0–1.0 (padrão 1.0). Desde o Opus 4.1, não aceita temperature e top_p na mesma chamada.
  • OpenAI: temperature 0–2 (padrão 1), top_p 0–1 (padrão 1). Recomendam mexer em um só.
  • Ajuste temperature primeiro; top_p só pra controle fino.
  • T = 0 não garante saída idêntica — há não-determinismo de execução/hardware.

Implementação de referência (TS)

function softmax(logits: number[], T = 1): number[] {
  const scaled = logits.map((l) => l / T);
  const max = Math.max(...scaled);
  const exps = scaled.map((s) => Math.exp(s - max));
  const sum = exps.reduce((a, b) => a + b, 0);
  return exps.map((e) => e / sum);
}

// sorteio "roleta" respeitando as probabilidades
function sample(probs: number[]): number {
  const r = Math.random();
  let cum = 0;
  for (let i = 0; i < probs.length; i++) {
    cum += probs[i];
    if (r < cum) return i;
  }
  return probs.length - 1; // fallback p/ erro de ponto flutuante
}

function topP(probs: number[], p: number): number[] {
  const idx = probs.map((v, i) => i).sort((a, b) => probs[b] - probs[a]);
  const keep = new Set<number>();
  let cum = 0;
  for (const i of idx) { keep.add(i); cum += probs[i]; if (cum >= p) break; }
  const kept = idx.filter((i) => keep.has(i)).reduce((s, i) => s + probs[i], 0);
  return probs.map((v, i) => (keep.has(i) ? v / kept : 0));
}

Pegadinhas

  • Sem subtrair o max antes do exp, logits grandes viram Infinity e o softmax vira NaN.
  • temperature é divisor: T < 1 aumenta o contraste, não diminui. Fácil de inverter na cabeça.
  • top_p = 0 não faz sentido (núcleo vazio); o mínimo útil ainda mantém ao menos 1 token.
  • Passar temperature e top_p pra Anthropic → erro. Escolha um.
  • Parâmetros de amostragem não consertam alucinação — só regulam diversidade vs. foco.
