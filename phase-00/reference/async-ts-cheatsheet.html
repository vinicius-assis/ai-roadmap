Colinha de Async TypeScript

O essencial comprimido. Imprima. Revise antes de cada lição de async.

Modelo central

  • Uma função async sempre retorna Promise<T>. return x resolve; throw e rejeita.
  • await p suspende somente a função atual até p se resolver; o event loop continua rodando.
  • Chamar uma função async a executa de forma síncrona até o primeiro await, e então devolve o controle para quem chamou.
  • await numa Promise rejeitada lança um erro naquela linha — capture com try/catch.

Mapa de sintaxe

Forma com PromiseForma com async/await
p.then(v => …)const v = await p
p.catch(e => …)try { … } catch (e) { … }
p.finally(() => …)try { … } finally { … }
Promise.all([a, b])const [x, y] = await Promise.all([a, b])

Padrões

// Função async tipada
async function fetchJson<T>(url: string): Promise<T> {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json() as Promise<T>;
}

// Trabalho paralelo e independente
const [a, b] = await Promise.all([tarefaA(), tarefaB()]);

// Paralelo, quer todos os resultados mesmo se algum falhar
const results = await Promise.allSettled([tarefaA(), tarefaB()]);
// results[i].status === "fulfilled" | "rejected"

// Sequencial — SÓ quando o passo N precisa do passo N-1
let acc = seed;
for (const step of steps) acc = await step(acc);

// Dormir
const sleep = (ms: number) => new Promise<void>(r => setTimeout(r, ms));

// Timeout / cancelamento (Lição 3)
const ac = new AbortController();
const timer = setTimeout(() => ac.abort(), 5000);
try { return await fetch(url, { signal: ac.signal }); }
finally { clearTimeout(timer); }   // limpa o timer nos dois caminhos

// Generator — protocolo (Lição 4)
function* g() { yield 1; yield 2; return 9; }
const it = g();
it.next();          // { value: 1, done: false }  — roda até o yield
it.next();          // { value: 2, done: false }
it.next();          // { value: 9, done: true }    — o return
// gen() NÃO roda o corpo; só cria o iterador (lazy).
// .next(x) injeta x como valor do `yield` que retomou.
// yield* outroIteravel  → delega.

// AbortController — a fundo (Lição 4)
const ac = new AbortController();
ac.signal;                       // passe para 1+ operações (fetch etc.)
ac.abort(reason?);               // cancela todas de uma vez
ac.signal.aborted;               // boolean
ac.signal.throwIfAborted();      // cheque dentro do seu próprio loop
AbortSignal.timeout(5000);       // timeout nativo, sem setTimeout manual
AbortSignal.any([s1, s2]);       // cancela se qualquer um cancelar
// no catch: err.name === "AbortError" | "TimeoutError" → é cancelamento, não falha

// Retry com backoff exponencial + jitter (Lição 3)
const base = 1000 * 2 ** tentativa;          // 1000, 2000, 4000...
const espera = base + Math.random() * base;  // + jitter, espalha o "herd"
// retry só em 429 e 5xx / rede / timeout. 4xx (400/401/404/422) NÃO.
// 429 → respeite o header Retry-After se vier.

// Criar um iterável assíncrono (Lição 2)
async function* stream(): AsyncGenerator<string> {
  for (const p of ["Oi", " ", "mundo"]) {
    await sleep(200);
    yield p;               // entrega um chunk, pausa até pedirem o próximo
  }
}

// Consumir um stream de tokens (Lição 2)
let completo = "";
for await (const chunk of stream()) {   // await implícito a cada volta
  completo += chunk;
  process.stdout.write(chunk);
}

Armadilhas

ArmadilhaCorreção
arr.forEach(async …) — não esperaUse for…of com await, ou Promise.all(arr.map(async …))
await sequencial para chamadas independentes — 2× de latênciaPromise.all
Erro async que ninguém espera → unhandled rejectionSempre termine a cadeia com await + try/catch ou .catch()
Esquecer o await → você recebe uma Promise, não o valorO TS costuma avisar; ative @typescript-eslint/no-floating-promises
await dentro de função não-async → erro de sintaxeMarque a função como async, ou use top-level await num módulo ES
